# Gestures make-creative

Start with this product's own substance: one mint editable donut, deformation, wire topology, sculpt pinches and hand-to-hand catch. Choose a visible metaphor from those interactions, such as a mode puck or a catch ripple. Keep one focal effect per event. Avoid decoration that competes with the live camera or moves the editing target. Prefer code-native CSS/SVG/Three effects over generated stock art. Compare before and after at the same viewport/state. Test actions as well as appearance, and state what requires user feel feedback. Preserve storage, export, history and camera ownership.
