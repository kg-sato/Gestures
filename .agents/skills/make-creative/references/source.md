# Make it creative (fix-and-record loop)

The user's standing request (2026-10-28): every part of the game should feel crafted and immersive, never generic. One line from them ("settings buttons too generic", "make the shop creative") is enough; do the whole loop below without asking for more. Full method and the record of every past fix: `Roblox Dev/Research/UI/Creative Fix Method.md`. Read it first, then append to its Log at the end.

## Loop
1. **Find the thing and capture it.** Locate the code (`Studio_Export/*.luau` mirrors Studio; GameClient holds the HUD). Play in Studio (MCP), open the thing, capture: `Hunyuan3D/.venv/Scripts/python.exe -I -c "import sys; sys.path.insert(0,'tools'); import ui_compare as u, cv2; im=u.grab_studio(); cv2.imwrite(sys.argv[1], im[190:970,318:1650])" out.png` (Play mode; window must be visible). Say in one line why it looks generic (same pill as everything else? flat? no motion? no story?).
2. **Research briefly** (one or two searches or a video frame study with `yt-dlp` + the sheet script): how do distinctive games do this kind of control? Note the idea, not pixels.
3. **Pick a metaphor from the world** (Lampwick Lane, fortune-teller, gaslight, brass, wax, tarot, candles, clocks, bells, lanterns, ledgers, rope, gauges, wings). The look is set by the user (2026-10-30): hyperreal, antique, sculpted magical steampunk: brass, rope, rivets, gauges, wings, Art Nouveau flourishes; whimsical (not straight) for the skill tree. One object per control; the object's own motion carries the feedback (a bell swings, a candle is lit or snuffed, a pointer slides, a card flips). Check the Metaphor Table in the method note first and reuse art that already exists.
4. **Art.** Reuse uploaded art (ids in `UI Kit/art/ids.json`, `VFX/textures/ids.json`). New object art: `python "UI Kit/art/comfy_generate.py" icon_obj_<name> --style sols --inbox --prompt "<object>, antique sculpted brass, engraved, rope and rivets, Art Nouveau scrollwork, painted, hyperreal"`; flat vector or clip-art output is rejected, ingest (`UI Kit/art/ingest_art.py`), crop to alpha, stop ComfyUI (port 8188), upload with Studio MCP `upload_image` from a localhost server (the user approved uploads of our own art). New effect sheets: `tools/fx_craft.py`; textures: `tools/fx_tex.py`.
5. **Build** in the module that owns it; keep the old behaviour and signals; one shared helper per idea (objectify, objImg) instead of copies. Big actions get a cutscene with the CutsceneFX kit, gated by `FXK.cineOff()`, `FXK.cineShort()` and `FXK.busy()`.
6. **Check in Play**: push sources (localhost server on `Studio_Export`, then set `.Source` in Edit), Play, capture or record (`tools/record_window.py`, sheet with the scratch sheet script), look at the frames, fix the biggest problem, repeat (usually 2 to 3 rounds). Every object's motion gets a sound (bell ring, latch click, candle hiss) through `SoundCatalog`; log the cues. Then blind grade: a fresh Opus subagent sees only the before and after stills (unlabelled) and `Roblox Dev/Research/Harsh Grading.md` (recipe in `Overnight/WORKER_BRIEF.md`), target 8 on every item; up to 8 rounds until it passes (the user, 2026-11-01). Watch for: dark text on dark art, things hidden behind the desk, white blow-outs under bloom, cameras inside geometry, local name clashes (`shade`), the 200-locals limit in GameClient (wrap new blocks in `do ... end`).
7. **Record**: copy before/after images to `Roblox Dev/Research/UI/Creative Fixes/`, add a Log row and any new metaphor to `Creative Fix Method.md`, and a bullet in `Roblox Dev/Session Log.md` only if it adds a lesson. Mirror changed scripts in `Studio_Export/`. Tell the user what changed, the blind scores, what was checked, what was not; look and feel stays UNVERIFIED until they judge it. Never commit unless asked.
