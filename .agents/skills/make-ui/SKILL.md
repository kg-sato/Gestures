# Gestures make-ui

Read the project frontend workflow and existing tokens. Compose existing controls rather than replacing the studio with a dashboard. The donut is the primary content. Keep inputs labelled, essential text at least 12px, tutorial prose readable, focus visible and controls within narrow viewports. Use native details/dialog semantics, named landmarks and one page heading. Preserve IDs used by the app and tests. Treat hover as optional, and enlarge touch targets without covering the artwork. Run scripts/test-frontend-skills.ps1, npm test and npm run build after changes. Inspect actual desktop and phone screenshots; lint is evidence to review, not permission to erase the product identity.
